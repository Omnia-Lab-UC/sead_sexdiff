# Proposal

## Why

The microglia positive control failed on E3: the first latent component follows the donor's mitochondrial UMI fraction (|ρ| 0.844) more closely than stage (0.688), and the same quality axis is the astrocyte primary's single component (`reports/motco-microglia-positive-control-2026-10-22.md`, `reports/motco-astrocyte-technical-axis-2026-10-19.md`). The mitochondrial fraction rises with stage in both cell types (median roughly tripling from stage 0 to 2), so stage and nucleus quality are entangled at the donor level, not the cell-type level. SEA-AD documented this structure (Gabitto et al. 2024): a PCA on library QC metrics identified 11 of the 42 high-ADNC donors as "severely affected" (fewer UMIs and genes detected despite more reads per nucleus, higher mitochondrial-encoded RNA, many fewer ATAC peaks, steeper memory decline), and the authors excluded them from every gene-expression test while keeping them in the composition models. The flag is in the donor objects' `obs` as `Severely Affected Donor` (`Y` / `N`; confirmed on the cluster on 2026-10-22 in both releases). Our pipeline keeps these donors everywhere; they are about a quarter of our stage-2 cell.

This change reads the flag, checks whether the quality gradient sits in the flagged donors, and runs a predeclared donor-exclusion sensitivity analysis: the whole export and the primary analysis rerun on the cohort donors without the flagged ones, for both cell types, following the data producers' own handling for expression tests. It is a sensitivity analysis, never a revised primary: the excluded donors carry the most severe pathology, so excluding them truncates the late epoch of the disease along with the quality tail, and the flag was made from QC metrics, so the variant conditions on quality by donor selection rather than by regression. The exclusion is predeclared by SEA-AD's flag, not chosen from our mitochondrial values or from any result.

## What Changes

- **A `donor-flags` step** (`--cell-type`, `--omic {rna,both}`, `--data-root`, `--out-dir`; cluster login node, `obs` only, seconds per object, modelled on `covariates`) that writes `<root>/pseudobulk/donor_flags.csv` and `donor_flags_manifest.json`: one row per non-Reference donor with `severely_affected` (from `Severely Affected Donor`, `Y` → true, `N` → false, anything else an error) and, recorded only, `cognitive_status`, `braak`, `cerad_score`, `thal`, `late` (strings as read) and `cps` (`Continuous Pseudo-progression Score`, present in the ATAC release only; the RNA release lacks it, recorded as a finding). RNA and ATAC values are cross-checked: a flag disagreement is an error, any other disagreement a finding with both values, the RNA value used. The step never writes `donor_covariates.csv` or `covariates_manifest.json`, so no existing hash chain moves. The flag table is an input of the exclusion step below and of nothing else.
- **A predeclared exclusion registry** `DONOR_EXCLUSION_VARIANTS` with one entry, `excluding_severely_affected` (exclude the cohort donors whose `severely_affected` is true); a constant, never a flag, entries added by a change proposal only.
- **An `exclusion-sensitivity` step** (`--cell-type`, `--variant`, `--cohort`, directory flags, `--n-jobs`, `--force`), per cohort:
  - reads and checks the primary export and analysis (`_check_export_reference`, `_check_reference`, as `preprocessing-sensitivity` does), the technical table (`_check_technical_reference`) and the flag table (cell type, completeness for the cohort donors), never rerunning or modifying them;
  - writes the **flag check** before any run (`flag_check/<cohort>/flag_check.csv`): the flagged donors per sex × stage cell; for each technical variable of the technical table and the primary export's TMM factors and library sizes, and for the primary `pls_0`, the rank-biserial AUC of flagged against unflagged donors, overall and within stage 2; the primary `pls_0`'s Spearman with stage and with each technical variable among the unflagged donors only. Descriptive, no p-value, never a gate: it says whether the quality gradient sits in the flagged donors; the variant runs whatever it says;
  - **reruns the whole export** (`_export_cohort`, the primary's thresholds, `EXPORT_EXCLUDED_CHROMOSOMES`, selection and normalization) on the cohort donors minus the excluded ones, with `k` recomputed from the remaining cells by the export's own rule (smallest sex × stage cell) and the exclusion recorded in the export manifest (`donor_exclusion`: variant, flag, flag-table hash, excluded donors, cells and `k` before and after); the cohort thresholds are not changed, so the variant cohort is `cohort_<t>` minus the flagged donors;
  - **reruns the analysis unchanged** (`_analyze_cohort`, six analysis covariates, `ANALYSIS_SEED`, `ANALYSIS_PERMUTATIONS`, CV rank, `n_jobs = 1` for reported results) on the variant export;
  - evaluates the **predeclared axis check** (`axis_check.csv`, `DONOR_EXCLUSION_AXIS_RULE`): along the variant analysis's first latent component, |Spearman| with stage exceeds the largest |Spearman| with a technical variable (the technical table's numeric columns for the variant donors plus the variant export's TMM factors and log10 library sizes; the same sources as E3, `POSITIVE_CONTROL_TECHNICAL_SOURCES`). Evaluated for both cell types; the microglia value is the change's expectation (the control cell type), the astrocyte value descriptive. No p-value; a comparison, not a test;
  - writes `comparison/<cohort>/` (`exclusion_sensitivity.csv` with the primary row and the variant row, `exclusion_sensitivity.md`, `exclusion_sensitivity_manifest.json`) under `<root>/motco_exclusion_sensitivity/<variant>/`, with `motco_input/<cohort>/` and `motco_analysis/<cohort>/` mirroring the primary layout so `axis-diagnostics`, `stage-de` and `stage-de-limma` can read the variant through their directory flags.
- **Stage DE on the exclusion cohort**, RNA only, both methods, both cell types, both cohorts: `stage-de --omic rna` and `stage-de-limma --omic rna` pointed at the variant's `motco_input/` and `motco_analysis/`, writing under the variant root. Their donor-agreement check applies the export manifest's recorded `donor_exclusion` to the donor table before comparing (the one code change in the DE steps; the fit records and every existing output stay as they are). The exported RNA stage counts (DESeq2 `factor_additive` union, limma `stage_joint`) beside the primary's say how much of the stage signal E1 counted survives the exclusion; the concordance cells apply to the variant analysis as to the primary.
- **Cross-cell-type comparisons in the report**, predeclared here and computed by the report's check script from the generated tables: the microglia exclusion-cohort CV AUROC against the astrocytes', and each cell type's exported RNA stage counts on the exclusion cohort against its primary counts. Compared, not tested.
- **Predeclared reading**, written before any run. The flag check and the axis check are read together: if the flagged donors carry the quality tail (high AUC for the mitochondrial fraction and the primary `pls_0`) and the axis check holds in microglia, the quality gradient of the primary analyses sits in the donors SEA-AD excluded from expression tests, and excluding them is a donor-selection route to the same end as the latent adjustment; if the axis check fails although the flagged donors carry the tail, the gradient extends beyond them and donor selection does not resolve it; if the flagged donors do not carry the tail, the flag is not the gradient's carrier and the variant is an ordinary cohort sensitivity. In every case the primary analyses and the primary-basis positive control stay as they are; a rejection status that differs between the variant and the primary is cohort dependence, not a result of the variant; a CV-selected rank that differs is reported beside `angle`; the non-rejection rules hold in the variant.
- **A committed report**, `reports/motco-donor-exclusion-sensitivity-<date>.md`, covering both cell types: provenance, the flag table's summary (flagged donors per cell type, cohort, sex and stage), the flag checks, the comparison tables, the axis checks, the stage-DE counts on the exclusion cohort beside the primary's with the concordance cells, the first-axis correlations of the variant from `axis-diagnostics`, the predeclared reading in the outcome that occurred, the reading rules and limitations.
- README and AGENTS.md document the two steps, the registry, the rules and the layout.

Out of scope: a revised primary cohort or any change to `COHORT_THRESHOLDS`, `ADNC_STAGES` or `PREREGISTERED_COHORTS`; CPS-based staging (recorded here, used by nothing; a later proposal); the flag as a covariate or as a diagnostic variable of `axis-diagnostics`; ATAC stage DE on the exclusion cohort; `rank-sensitivity`, `preprocessing-sensitivity` or `latent-sensitivity` on the variant; any change to the expectations E1–E3 or to any primary output or reading.

## Capabilities

### New Capabilities
- `donor-flag-table`: SEA-AD's donor-level flags and staging labels (`severely_affected`, cognitive status, Braak, CERAD, Thal, LATE, CPS) read from the donor objects' `obs` into a table apart from the covariate table, cross-checked between omics, used by the exclusion step and nothing else.
- `donor-exclusion-sensitivity`: the predeclared donor-exclusion registry, the flag check, the variant export and analysis on the unflagged cohort donors, the axis check, the generated comparison, the stage DE on the exclusion cohort and the committed report with its reading rules.

### Modified Capabilities
- `pseudobulk-stage-de`: the donor-agreement check between the export, the donor table and the count files applies the donor exclusion the export manifest records, if any, so the step can run on an exclusion-cohort export (the limma step reuses the same preparation).

## Impact

- Depends on `mtg-microglia-positive-control` (PR #12) being merged: the registry, `--cell-type`, the microglia results root. This branch is based on it. Independent of `mtg-microglia-latent-sensitivity` (both may be applied in either order; each reads the other's outputs nowhere).
- `src/sead_sexdiff/data.py`: `DONOR_FLAG_COLUMNS`, `DONOR_FLAG_ATAC_ONLY_COLUMNS`, `DONOR_FLAG_OUTPUTS`, `read_donor_flags`, `run_donor_flags`; `DONOR_EXCLUSION_VARIANTS`, `DONOR_EXCLUSION_AXIS_RULE`, `DONOR_EXCLUSION_CHECK_VARIABLES`, the `DONOR_EXCLUSION_*` output names, `flag_check`, `axis_check`, `run_exclusion_sensitivity`, `render_exclusion_sensitivity`; `_export_cohort` gains a `donor_exclusion` keyword recorded in the manifest (absent by default, so the primary export is byte-identical); `_stage_de_prepare` applies a recorded `donor_exclusion` before the donor-agreement check and records it in the fit manifests (the fit-record fingerprints are unchanged). `CELL_TYPE_SUBDIRS` gains `motco_exclusion_sensitivity`.
- `src/sead_sexdiff/cli.py`: `donor-flags` and `exclusion-sensitivity` subcommands.
- `scripts/sync_pseudobulk.sh` needs no change (it syncs the directory; the per-donor caches stay excluded).
- `reports/`: one new committed report. `results/` stays gitignored.
- Compute: on the cluster, `donor-flags --omic both` for each cell type's pseudobulk directory (minutes, `obs` only); on the workstation, per cell type two export reruns and two CV analyses (about a minute each), two `axis-diagnostics`, RNA `stage-de` and `stage-de-limma` on two cohorts (minutes).
- Scientific choices introduced here (flag and ask before changing): the registry with SEA-AD's flag as the only exclusion; the thresholds kept and `k` recomputed by the export's rule; the flag check's variables and statistics (rank-biserial AUC, Spearman, no p-value); the axis check with E3's technical sources, the microglia value as the expectation; RNA-only stage DE on the exclusion cohort; the recorded-only columns of the flag table; the predeclared reading; and the rule that the primary analyses, the primary cohorts and the positive control's outcome are unchanged by anything found here.
