# Proposal

## Why

Every astrocyte MOTCO analysis so far is a non-rejection with a weak latent space (CV AUROC 0.63 / 0.66, rank 1, first axis technical until the latent adjustment removes it; `reports/motco-astrocyte-2026-10-19.md`, `reports/motco-astrocyte-latent-adjustment-2026-10-21.md`). MOTCO's operating characteristics are simulated (Phase 6, InterSIM-shaped blocks), so nothing yet shows that the pipeline, run on real SEA-AD donor pseudobulks, builds a latent space that resolves ADNC stage at all. Without that, the astrocyte null cannot be told apart from a pipeline that cannot see stage structure in this data. The per-feature stage DE of the same pseudobulks does not separate the two readings either: both predeclared methods found little stage signal (in RNA one gene, `CREB5`, in both; `reports/motco-astrocyte-stage-de-2026-10-21.md`, `reports/motco-astrocyte-stage-de-limma-2026-10-22.md`).

A cell type with a documented ADNC-stage response gives that check. Microglia carry the strongest reported stage-associated transcriptional response in the SEA-AD MTG. Running the unchanged pipeline on microglia pseudobulks, with expectations written down before any run, tests whether the latent construction resolves stage on real data. It is a positive control for the stage signal, not for the sex × stage hypothesis: whether microglial trajectories differ by sex is open, and that result is read under the same binding rules as the astrocyte one.

## What Changes

- **A cell-type registry** `CELL_TYPES` keyed by canonical name, each entry holding the per-release `Subclass` label(s) and the `Supertype` labels that define the population, the results root, and the preregistered cohort cells:
  - `astrocyte`: the current mapping (`Astrocyte` in both releases, `Astro_1`…`Astro_6-SEAAD`), results root `results/`, the current `PREREGISTERED_COHORTS`. The default. Every astrocyte output is unchanged.
  - `microglia`: RNA release 2026-06-22 `Subclass` `Immune`, ATAC release 2024-12-06 `Subclass` `Microglia-PVM`, restricted to the microglia / PVM `Supertype` labels of each release (the `Immune` subclass also holds lymphocyte and monocyte supertypes, which are not microglia); results root `results/microglia/`. The exact labels and the preregistered cohort cells come from a spike on the donor objects' `obs` columns (metadata only, run before any pseudobulk), recorded in `spike.md`.
  - Entries are added by a change proposal only; the name is a flag (`--cell-type`), the mapping is not.
- **Every MTG step takes `--cell-type`** (default `astrocyte`): `pseudobulk`, `covariates`, `technical-covariates`, `export`, `analyze`, `axis-diagnostics`, `stage-de` and `stage-de-limma` (both merged: `mtg-astrocyte-stage-de`, PR #10; `mtg-astrocyte-stage-de-limma`, PR #11). The flag sets the default directories under the cell type's results root (`<root>/pseudobulk/`, `<root>/motco_input/`, …); explicit directory flags still win. The nucleus selection stays one code path, now parameterized by the registry entry; the pseudobulk and the technical step keep selecting the same nuclei.
- **Cell type recorded and checked through the chain.** Every manifest records `cell_type`; `export` checks it against the pseudobulk manifest; `analyze`, `axis-diagnostics`, `stage-de` and `stage-de-limma` against the export manifest; `stage-de-limma` also against the DESeq2 stage-DE manifest it reads. An astrocyte export can never be analysed as microglia or the reverse.
- **Cohorts:** the same `COHORT_THRESHOLDS` (≥ 30 / ≥ 50 nuclei in both omics), the same `ADNC_STAGES`, `k` computed per cohort as now. The microglia preregistered cells are written into the registry from the spike before the pseudobulk runs; deviations go to the manifest as findings. If the spike shows that the thresholds leave a sex × stage cell empty, the thresholds for microglia are decided in this proposal from those counts (metadata), before any pseudobulk, export or analysis, never from a result.
- **Predeclared positive-control expectations** `POSITIVE_CONTROL_EXPECTATIONS`, evaluated per cohort by a new `positive-control` step from the generated files of both cell types, written to `results/microglia/positive_control/`:
  - E1 (stage signal): under each of the two predeclared stage-DE methods, the number of exported RNA features with a stage effect at FDR 0.05 is larger in microglia than in astrocytes, compared within the method: `stage-de` (DESeq2, `factor_additive`, the union of its two coefficients) and `stage-de-limma` (limma-voom, `factor_additive`, the joint moderated F `stage_joint`). E1 holds only when it holds under both methods. When it holds under one only, E1 is recorded as `method_dependent`, which counts as not holding, and the report names the method under which it held: no method is promoted, and the control cannot rest on one method.
  - E2 (latent separation): the microglia primary analysis's `cv_mean_auroc` exceeds the astrocyte primary analysis's.
  - E3 (axis identity): along the first latent component of the microglia primary analysis, `|Spearman|` with stage exceeds `|Spearman|` with every technical variable of `DIAGNOSTIC_VARIABLES` (from `axis-diagnostics`).
  - The control holds when E1–E3 all hold in the primary cohort. If it holds, the pipeline resolves stage structure on real data and the astrocyte null is not a pipeline failure. If it does not, the latent construction is in question for any cell type, and that is reported. No expectation reads a p-value, a rejection or a MOTCO statistic. The values are compared, not tested.
- **The microglia sex × stage analysis** itself (`analyze` on the microglia export, six analysis covariates, same seed, permutations, orientation and CV selection) is a second case-study result, read under the existing rules: a `delta` rejection is a difference, not specifically of size; `angle` and `shape` non-rejections are uninformative; the CV-selected rank beside `angle`; MOTCO's Phase 6 operating characteristics carried as limitations (measured on neither cell type's blocks). Both stage-DE concordance rules apply to it as to the astrocytes: the DESeq2 cell (`STAGE_DE_CONCORDANCE_RULE`), the reported one, and the limma cell (`STAGE_DE_LIMMA_CONCORDANCE_RULE`, `interaction_joint`) beside it with `methods_agree`; a disagreement is method dependence, a result of neither method.
- **Outputs** mirror the astrocyte layout under `results/microglia/` so every existing reader (`rank-sensitivity`, `preprocessing-sensitivity`, `latent-sensitivity`, `axis-diagnostics`) can later be pointed at it through the directory flags; those sensitivity analyses are not run here.
- **A committed report**, `reports/motco-microglia-positive-control-<date>.md`: provenance, the spike, cohort tables, the primary analysis summary, the stage-DE counts of both cell types and both methods side by side, both concordance cells, the E1–E3 table, the first-axis correlations, the reading rules and limitations.
- README and AGENTS.md document the registry, the flag, the step and the reading rules.

Out of scope: other cell types (an entry each, by proposal); sensitivity analyses on microglia; a cross-cell-type MOTCO comparison; changing any astrocyte output or constant; any adjustment of the astrocyte reading from the microglia result.

## Capabilities

### New Capabilities
- `cell-type-positive-control`: the cell-type registry with its microglia entry, the `--cell-type` wiring and cross-manifest checks of the MTG steps, the predeclared expectations E1–E3 (E1 under both stage-DE methods) with the `positive-control` step that evaluates them, both stage-DE methods and concordance cells on microglia, and the committed report.

### Modified Capabilities
- `astrocyte-donor-pseudobulk`: nucleus identification goes through a registered cell type (default astrocyte, outputs unchanged); the manifest records the cell type and the results root follows it.
- `donor-cohort-table`: the preregistered cohort cells are per cell type; the microglia cells come from the spike.
- `donor-technical-table`: "same nuclei as the pseudobulk" is the pseudobulk of the same registered cell type, checked through the manifest.
- `motco-input-export`: reads the cell type's pseudobulk directory and refuses a cell-type mismatch; records the cell type.
- `motco-trajectory-analysis`: reads the cell type's export and refuses a mismatch; records the cell type.

## Impact

- Builds on `mtg-astrocyte-stage-de` (PR #10) and `mtg-astrocyte-stage-de-limma` (PR #11), both merged: their `stage-de` and `stage-de-limma` steps evaluate E1 and the two concordance rules. Their astrocyte outputs (`results/stage_de/`, `results/stage_de_limma/`) are E1's reference and are read, never rerun.
- `src/sead_sexdiff/data.py`: `CELL_TYPES`, `TAXONOMY` restructured per cell type and release (astrocyte values unchanged), `PREREGISTERED_COHORTS` per cell type, `select_astrocyte_nuclei` generalized to `select_nuclei(cell_type=...)` with the astrocyte name kept as a wrapper, `cell_type` threaded through `run_pseudobulk`, `run_covariates`, `run_technical_covariates`, `run_export`, `run_analysis`, `run_axis_diagnostics`, `run_stage_de` and `run_stage_de_limma` (defaults reproduce today's behaviour and outputs byte-identically; `stage_de_limma.R` is not edited, since its sha256 is in every limma fit record), `POSITIVE_CONTROL_EXPECTATIONS`, `run_positive_control`, `render_positive_control`, output names. Every manifest gains `cell_type`.
- `src/sead_sexdiff/cli.py`: `--cell-type` on the eight MTG commands; new `positive-control` subcommand (`--cohort`, `--control-root`, `--reference-root`, `--out-dir`, `--force`).
- `scripts/pseudobulk.sbatch`, `scripts/technical.sbatch`, `scripts/sync_pseudobulk.sh`: take the cell type (default astrocyte).
- `reports/`: one new committed report plus `spike.md` in the change. `results/` stays gitignored.
- Compute: on the cluster, an `obs`-only spike over all 170 objects (minutes), then `pseudobulk --cell-type microglia --omic both` (the RNA objects are the cost; about the astrocyte run's time), `covariates`, `technical-covariates`; on the workstation, `export`, `analyze` (about a minute per cohort), `axis-diagnostics`, `stage-de`, `stage-de-limma` (in the Nix shell; minutes for ATAC), `positive-control`.
- Scientific choices introduced here (flag and ask before changing): the registry and the microglia label mapping, the reuse of the astrocyte thresholds and stage coding, the expectations E1–E3 and the rule that all three must hold in the primary cohort, the use of the exported RNA set for E1, the rule that E1 must hold under both stage-DE methods (a method disagreement counts as not holding), and the rule that the astrocyte analysis and its reading are unchanged by anything found here.
